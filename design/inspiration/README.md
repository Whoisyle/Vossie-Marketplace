# Motion and visual inspiration

> The owner keeps the real inspiration files in `C:\Users\PABAL\OneDrive\Desktop\Vossie Design Inspiration`. Read from there; do not copy large media into git. Copy a file here only when a build needs it.

Drop references here: screenshots, screen recordings (.mp4, .mov, .gif), Lottie/JSON files, and a `links.md` for URLs.

Name files by the screen they inspire so they are easy to match, for example:

- `01-intro-dot-bounce.mp4`
- `02-intro-warp-transition.mp4`
- `04-signin-bubbles.gif`
- `06-home-floating-navbar.png`
- `reels-icon.png`

Pinterest links often cannot be opened by tools, so save the image or video itself into this folder when you can. Add one line per file to `links.md` saying what to copy from it (the timing, the shape, the colour, the feel).

References inform the motion; they do not override the Vossie brand identity or the accessibility rules (reduced motion respected, 44pt targets).
