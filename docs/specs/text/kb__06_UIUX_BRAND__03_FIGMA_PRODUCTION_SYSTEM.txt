Build order
Brand/tokens → primitives → shared patterns → role patterns → priority journeys → full screen families → responsive
states → motion specs → clickable prototype → developer handoff.
Component discipline
Use Figma V ariables, Styles, Components, V ariants and Auto Layout. A void meaningless frame names.
Examples:
• Marketplace/ListingCard/Food/Default
• Marketplace/Reel/ProductRail
• Courier/JobCard/Available
• Hub/PackageCard/AwaitingScan
• Operations/IncidentCard/Critical
States
Default, focus, pressed, hover where relevant, loading, disabled, success, error, offline, empty , retry , expired, denied, pend-
ing/review.
Handoff
Map Figma variables → code tokens; components → React components; variants → component states; frames → routes;
responsive variants → container/breakpoint behaviour; motion specs → Motion.dev/CSS.
Automated Figma writing is an accelerator only when the connected plugin/account supports it; do not assume write access
exists.
