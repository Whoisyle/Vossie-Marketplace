Decision 01 — Single-deployment adaptive PWA
Vossie uses one URL/QR entry point and one shared application platform. The interface adapts to available screen
space and capabilities rather than maintaining separate phone and desktop products. All clients share authenticated
backend state, APIs, data and realtime events.

Decision 02 — Multi-agent development architecture
The development model separates architectural coordination, implementation and independent verification. ChatGPT
acts as the cross-environment second brain and technical architecture/orchestration layer. Cursor is an
implementation environment that contains both the ChatGPT-assisted workflow and Cursor-native agents/skills. VS
Code is the engineering control and verification environment.
The agents do not rely on shared conversational memory. Git, repository specifications, ADRs, contracts, tests and
documented handoffs form the persistent source of truth.

E. Engineering workflow
1. Developer selects a feature. 2. ChatGPT decomposes it into architecture, contracts, risks and implementation
tickets. 3. Cursor-native agents implement scoped tickets using shared skills. 4. Work is committed to a feature branch
and submitted as a PR. 5. VS Code verification agents inspect security, tests, contracts and runtime behavior. 6. CI
executes automated gates. 7. Failures return to implementation; approved work merges to protected main.
 Cursor builds; VS Code verifies; ChatGPT coordinates architecture; Git and documented
specifications preserve truth.
F. Mandatory agent boundaries
Rule
Requirement
Protected main
No agent pushes directly to main.
Scoped work
Agents modify only ticket-authorized areas unless escalation is documented.
Architecture
Agents cannot silently change architecture; significant changes require an ADR.
Database
Migrations require review; destructive changes need explicit approval.
Auth/security
Authentication, authorization and RLS changes require security verification.
Payments
Ledger/payment changes require dedicated invariants, idempotency and failure-path tests.
Tests
Agents may not remove/disable tests merely to make CI pass.
Secrets
No secrets in prompts, source, commits or logs.
Completion
Feature = implementation + tests + docs + security/quality checks + handoff.
G. Standard agent handoff
Every implementation handoff must state: ticket/branch; files changed; migrations; APIs/events changed; environment
variables; tests added; test results; security considerations; known limitations; unresolved questions; and the exact
verification requested from the next agent.
H. Initial team size
Start with four Cursor build agents — Frontend; Backend/Database; Marketplace/Logistics; Integrations/Realtime —
and four VS Code verification roles — Security; QA/Testing; Review/Debug; Git/Release. Split into more specialized
agents only when project complexity justifies it.
Repository source-of-truth structure
/docs/architecture   /docs/adr   /docs/api   /docs/database   /docs/security  
/docs/ui-ux   /agent-context
The agent-context area should contain architecture rules, coding standards, security rules, database rules, UI rules
and the definition of done so both IDE workflows reference the same engineering constraints.

B. Identity: Clerk added as a formal candidate
Clerk is added behind a Vossie Identity Provider boundary. It is not layered on top of Supabase Auth by default. The team
will select Clerk or Supabase Auth for the prototype identity/session layer after validating institutional federation,
authorization mapping, cost, developer experience and migration path.

Regardless of provider, Vossie owns its profile, role/capability and resource-scope model. Institutional passwords and
authenticator secrets are never collected by Vossie.
C. SwiftUI native iOS expansion layer
SwiftUI is added to the architecture as an optional native iOS layer, not as a replacement for the Next.js PWA. The PWA
remains the universal prototype and desktop/mobile baseline. SwiftUI becomes justified when validated requirements
exceed reliable web/PWA capability - for example richer Apple-specific UX, native camera/scanning, stronger native
notification behavior or courier location/background workflows.
